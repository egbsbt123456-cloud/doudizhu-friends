# 斗地主 · 好友牌桌

三人在线斗地主：登录账号、建房邀请好友、准备、叫分、出牌、不出、刷新恢复、再来一局。单屏牌桌、重叠手牌、地主冠徽与农民麦穗徽章；手机竖屏提示旋转，横屏完整显示。

基于 [NFraw/Tongzhuo](https://github.com/NFraw/Tongzhuo) 的 MIT 斗地主模块及用户提供的修复版，保留原作者许可；改动说明见 NOTICE。前端使用 Vue，接口使用 Fastify，房间保存到 SQLite。这里只有斗地主和必要的账号/房间基础代码。

## 本地运行

安装 Node.js 24、pnpm 10.34.9。Windows 使用原生模块时建议使用受支持的 Node 版本；原生模块若需源码编译，按 better-sqlite3 安装要求准备工具链。

```sh
pnpm install --frozen-lockfile
# 将 .env.example 复制为 .env，保持本地地址配置
pnpm db:migrate
pnpm dev
```

浏览器访问 http://localhost:5173/games/doudizhu 。三个玩家各登录自己的账号，分别使用设备、浏览器或独立浏览器配置；同一浏览器的普通标签页共享账号。

```sh
pnpm test
pnpm typecheck
pnpm build
```

## 规则

54张，每人17张，留3张底牌。先暗叫；0分不叫，1–3分递增，3分直接当地主。首轮无人叫，亮底牌再叫；第二轮仍无人叫则重发。暗地主底牌仅地主可见，明地主底牌全桌可见。地主20张先出，地主与两位农民分队，任一方先出完获胜。

同型同张数才能压，炸弹压普通牌，王炸最大；支持顺子、连对、三带一/对、飞机带单/对、四带二与四带两对。四带二允许带一对，飞机带单保留原版必须独立单张的口径。两家不出后恢复自由出牌，不可继续不出。保留炸弹/王炸倍率，没有春天、正式积分、余额或金钱结算。

## 生产部署

使用一个**全新的专用数据库**。本包迁移1与主站迁移8不是同一迁移历史，不能把生产主站数据库复制进来使用。

构建后 `pnpm start` 启动后端，反向代理托管 `apps/web/dist`，把 `/api/*` 和 `/socket.io/*` 转发到后端。参考 Caddyfile.example，将域名、文件目录和 `.env` 的 `WEB_ORIGIN` 换成你自己的值。生产设置 `NODE_ENV=production`；账号和房间仅在 HTTPS origin 下开放。生产不要将数据库或 `.env` 放到静态目录。

HTTP接口根据登录会话生成自己的视图；完整手牌、洗牌序列不会发给客户端。客户端1.2秒同步，操作附带请求编号和版本，不做乐观扣牌。SQLite事务防止重复出牌/叫分；断线保留座位，计时继续。每回合30秒，超时叫分不叫、跟牌不出、自由领出最小单张；服务器持久化期限并每秒处理，刷新不重置。手机方向锁定需要浏览器支持，不支持时按提示手动横屏。

## 验证和边界

原项目41项牌型测试保留，另有规则长局、底牌可见范围、请求防重/版本、权限和重启恢复测试；独立包共49项测试已通过，类型/构建和新库服务启动通过，三账号真实HTTP接口检查通过。没有AI、同屏多人、观战、匹配、第三方语音及音频素材。实体手机与不同设备的实际体验请自行验收。
